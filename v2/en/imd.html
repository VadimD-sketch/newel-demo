IMD – Individual Metering and Billing

Everyone pays for their own charging, without the association or property owner bearing the cost.

Request a quote for IMD Ask us

How IMD works

  1. 1

    Consumption is measured

    Electricity consumption is measured for each user while charging.

  2. 2

    The cost is linked to the user

    Consumption is tied to the right user and charging space.

  3. 3

    The user is billed

    Each user is billed for their actual consumption. [DESCRIBE INVOICING AND PAYMENT]

Why IMD for charging

Fair cost allocation

Whoever charges pays for their charging. Everyone else in the association or property is unaffected.

Clear documentation

Consumption and cost per user can be followed up. [DESCRIBE REPORTS AND DOCUMENTATION]

Simpler administration

Less manual work for the board, managers and finance staff. [CONFIRM WITH NEWEL]
